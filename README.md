# Guide You Watch Companion website
Plain static HTML/CSS, no build step (fastest to deploy on GitHub Pages).
Files: index.html, privacy.html, terms.html, style.css, assets/.
Waitlist: Formspree. Create a form at formspree.io and replace YOUR_FORM_ID in index.html; submissions appear in the Formspree dashboard and email.
Privacy and Terms are drafts built from the app's DATA_INVENTORY.md; reconcile with the authoritative doc.
